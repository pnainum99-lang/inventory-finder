# Inventory Finder V2

A responsive React/Vite prototype for resale inventory sourcing.

## V2 additions
- Quick inventory entry
- Advanced search and filters
- Deal score based on margin, condition, source and risk
- Pipeline/status tracking
- CSV export
- JSON backup/restore
- Duplicate SKU/listing detection
- Local browser storage
- Mobile responsive UI

## Run
Install Node.js LTS, then:
npm install
npm run dev

## Production note
V2 is still a prototype. Before using it for real business data, add a server database, authentication, staff permissions, audit logs, backups and secure handling of seller/customer contact data.
